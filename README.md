# 呈分試試卷搜尋器

香港小學呈分試（小五下・小六上・小六下）中英數試卷搜尋工具。內嵌 234 份公開試卷索引，可按科目、年級學期、年份、學校篩選。單一 `index.html`，手机浏览器可直接打开。

## 臨時線上網頁（無需下載）

- 公開連結（約 72 小時）：https://litter.catbox.moe/wa16nw.html

手機 Safari / Chrome 直接打開即可用篩選。

## 永久託管（建議）

本倉庫已放好檔案。在 GitHub 開 GitHub Pages 即可得到永久網址：

1. 打開 https://github.com/windart119/tsa-searcher/settings/pages
2. Source 選 **Deploy from a branch**
3. Branch 選 `main`，資料夾 `/ (root)`，Save
4. 約一兩分鐘後開啟：https://windart119.github.io/tsa-searcher/

## 本機使用

下載 [index.html](./index.html) 用瀏覽器打開即可（資料已內嵌，唔使 papers.json）。

資料來源為網上公開連結，僅供學習參考。試卷版權屬原作者／學校。
